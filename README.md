# Stats Club BMX

**[🇬🇧 English](#english) · [🇫🇷 Français](#français)**

Part of [Sqorz Hub](https://ludsoc.github.io/sqorz-hub/) — BMX Race statistics tools.

---

## English

Analyze a BMX Race club's performance across seasons: rankings, win rates, active pilots, and year-over-year evolution.

### Features

- Search any club from Sqorz data
- Win rate and podium rate per year
- Active pilot count evolution
- Top pilots ranking
- Shareable URL (saves selected club)

### Live

**[ludsoc.github.io/sqorz-club](https://ludsoc.github.io/sqorz-club/)**

### Tech

Single-file HTML/CSS/JS, no framework, no build step. Data from the public [Sqorz API](https://our.sqorz.com).

> Community project, not affiliated with Sqorz.

---

## Français

Analysez les performances d'un club BMX Race sur plusieurs saisons : classements, taux de victoire, pilotes actifs et évolution d'une année sur l'autre.

### Fonctionnalités

- Recherche de n'importe quel club dans les données Sqorz
- Taux de victoire et taux de podium par année
- Évolution du nombre de pilotes actifs
- Classement des meilleurs pilotes
- URL partageable (mémorise le club sélectionné)

### Accès

**[ludsoc.github.io/sqorz-club](https://ludsoc.github.io/sqorz-club/)**

### Technique

HTML/CSS/JS en fichier unique, sans framework, sans étape de build. Données issues de l'[API publique Sqorz](https://our.sqorz.com).

> Projet communautaire non officiel, non affilié à Sqorz.
